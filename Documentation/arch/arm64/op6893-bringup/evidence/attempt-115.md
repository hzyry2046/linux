# attempt115：I2C 读取错位

内核 `ef0166990cda`。

- 现象：i2c0 设 400 kHz 时约 1–2% 的 FT3518 读取出现字节重复/错位。
- 测量：同一总线读 8 字节与 63 字节的耗时差算出每字节时间，实际 SCL 约
  490 kHz，高于设定的 400 kHz。
- 根因：DT 里 `i2c_ck` 占位时钟已经是 124.8 MHz 源时钟，又照抄了厂商的
  `clock-div = <5>`。主线驱动会再除以 5，按约 25 MHz 计算时序，实际总线偏快。
  （Mu 和厂商驱动是把 5 分频写进 CLOCK_DIV 寄存器，含义不同。）
- 修复：i2c0、i2c5 都改为 `clock-div = <1>`，i2c0 恢复 400 kHz（与厂商 DT 一致）。
- 结果：实测约 390 kHz；1000 次连续 63 字节读取完全一致；20 秒连续滑动 826 帧，
  无越界坐标、无大于 300 像素的跳变；buffyboard 正常。
