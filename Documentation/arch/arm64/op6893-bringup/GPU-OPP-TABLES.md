# MT6893 GPU OPP Tables (from downstream 4.19)

提取自 `drivers/gpu/mediatek/gpufreq/v1/include/mt6893/mtk_gpufreq_internal_plat.h`。

## Segment 识别

通过 efuse `0x11C107B0[2:0]` 判断：
- `0x2`: segment 2 (高电压版本)
- 其他: segment 1 (默认)

代码在 `mtk_gpufreq_plat.c:__mt_gpufreq_get_segment_table()`。

## 关键信息

- **电压单位**: mV × 100（80000 = 0.8V）
- **PMIC 步进**: 625（= 6.25mV）
- **Vsram 规则**:
  - `vgpu <= 75000`: `vsram = 75000` (固定 0.75V)
  - `vgpu > 75000`: `vsram = vgpu + 0` (FIXED_VSRAM_VOLT_DIFF = 0)
- **PMIC 范围**:
  - Vgpu: 0.3V ~ 1.19375V
  - Vsram_gpu: 0.5V ~ 1.29375V
  - Buck diff: -100mV ~ +300mV
- **PLL**:
  - POSDIV_POWER_4: post-divider = 4，适用 375–950 MHz
  - POSDIV_POWER_8: post-divider = 8，适用 187.5–475 MHz
  - MFGPLL input: 26 MHz

## Mainline 移植

需要：
1. 在 DTS 中添加 `operating-points-v2` 表，频率/电压对应上表。
2. 添加 `vgpu` 和 `vsram-gpu` regulator 绑定。
3. Panfrost devfreq 会自动使用 OPP 表调频调压。
4. 注意 segment 识别需要读 efuse（nvmem），或直接用 segment 1 表。

## DVFS 相关寄存器（参考）

- MFGPLL_CON1: `apmixed_base + 0x026C`
- MFG QOS控制: 见 `mtk_gpufreq_plat.c` 的 power control 部分
- 调频通过 frequency hopping (`mtk_freqhopping_drv.h`) 实现
